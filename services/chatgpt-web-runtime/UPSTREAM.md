Health ports are allocated per process on loopback. ## Saved sessions and Chrome import

Status refreshes never verify a session or send a provider prompt. In **Connection**, use **Verify saved session** before opening another sign-in browser. A waiting viewer lease must be completed or ended explicitly; verification/import will not close it. A UI probe failure is not proof of session expiration. ChatGPT may revoke cookies before their recorded expiry; challenges/2FA require normal sign-in, not a bypass.

Chrome session assistant (desktop Chrome):

1. Choose **Add Connection**, enter a name, select **Chrome extension** or **Private browser**, then **Continue**. Creating a connection does not start sign-in or upload credentials. Saved connections have separate **Connection**, **Coding agents**, **Preferences** and **Diagnostics** tabs; unsaved preferences survive tab changes and revision conflicts.
2. In **Connection**, choose Chrome sign-in. Under **Install or update helper**, download the ZIP, extract it, enable Developer mode at `chrome://extensions`, then **Load unpacked** the extracted folder containing `manifest.json`. Reload the extension after updating that folder. Do not load `tools/chatgpt-web-session-export` directly: its imports require bundling.
3. Sign in at `https://chatgpt.com` in that Chrome profile. Return to the dashboard tab and open the helper icon or **Alt+Shift+9**. The dashboard prepares an eligible five-minute exact-profile/revision target; compare its server/connection before explicitly clicking **Connect to this 9Router**. Opening/focusing the helper or **Check connection again** only refreshes metadata, never reads cookies or submits credentials. Blocked states explain the next action; the helper cannot connect from the ChatGPT tab.
4. The helper hands an in-memory File to the authenticated dashboard's same-origin importer. Leaving the assistant/tab, dirty settings, expiry or runtime actions invalidate its target. Consumed/unknown attempts never replay or silently renew; inspect the connection and explicitly **Verify saved session** before a new attempt.
5. **Manual transfer** in the helper offers Copy JSON/Export file; **Manual import** in the dashboard offers paste/file input. Selection alone never uploads. Credentials clear after submission/error, mode/profile changes and closure. Treat clipboard history and exports as credentials; delete exported files after importing, never send them to support. Denied clipboard writes do not silently download or send anything.
6. **Change sign-in method** selects the private browser. Sign in/MFA yourself, then **Finish Sign In**. Mobile, Firefox and Safari use that path or a desktop Chrome export; extension compatibility is not assumed.

The helper requests `cookies`, `activeTab` and `scripting`, with permanent host access only to `https://chatgpt.com/*`. Its popup/worker cannot fetch remote servers (`connect-src 'none'`); only isolated scripts on the explicitly selected active dashboard document perform authenticated read-only prechecks and the File handoff. Only unpartitioned ChatGPT cookies transfer, preserving HttpOnly/Secure/SameSite and multipart parts; no Google cookies, passwords, localStorage or access-token API is read. The stable manifest key is public, not a credential. A DOM marker cannot prove a server is trustworthy: the user's consent to the actual origin and backend dashboard authentication remain required.

Import requires HTTPS, except socket-trusted HTTP loopback development; forwarded protocol headers cannot grant that exception. Active turns, waiting viewers, dirty drafts and draining/probing profiles block import. Account mismatch restores the old cookies without replacing its binding. A lost observer never retries: inspect the connection, then explicitly **Verify saved session**. On `session_restore_failed`: **The previous browser session could not be restored. Do not retry the import; contact the operator.**

Endpoints are `POST /admin/session/verify` with `{profileId, revision}` and `POST /admin/session/import` with `{profileId, revision, session}`. They require the runtime admin token; gateway dashboard authentication and same-origin checks remain mandatory. Import format is exactly `{format:"9router-chatgpt-session",version:1,cookies:[...]}`. No session file/payload is stored in the gateway database. Runtime persistent Chromium keeps cookies in the same profile directory. Missing new endpoints on an old runtime return `runtime_upgrade_required`, not a silently replayed/manual login.
